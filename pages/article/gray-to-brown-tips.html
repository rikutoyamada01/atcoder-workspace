灰レーティング脱出！茶色になるまでに絶対に押さえるべき解法 & 実践Tips

著者: rikuto yamada · 更新日: 2026年10月15日

対象: 灰コーダー (Rating 0 ~ 399) → 目標: 茶コーダー (Rating 400+) 読了時間: 約 5 分

「AtCoder を始めたけど、なかなか灰色を脱出できない」「C問題になると急に解けなくなる……」とお悩みではありませんか？
まずは全探索やソートなどの基本的な解法から練習できます。必要な知識は問題によって異なるため、このガイドを出発点にして解ける問題を増やしていきましょう。

ここでは基本となる「4つのパターン」を練習し、「ペナルティ（WA・TLE）を出さない丁寧さ」を身につけることです。この記事では、灰コーダーが茶色になるための最も効率的な実践Tipsをまとめました！

1. 灰脱出に向けて練習したい「4つの基本パターン」

ABC（AtCoder Beginner Contest）の A・B・C 問題で取り組む際に役立つ4つのパターンです。出題内容や必要な知識は回によって変わるため、まず基本の練習に使ってください。

① 全探索（全ペア比較・二重ループ）

考えられる全ての可能性を試す最も確実な解法です。制約 $N \le 2000$ 程度なら、二重ループ $O(N^2)$ の全探索を検討できます。正しさ・1回あたりの処理・時間制限を確認してください。

// 全ペア (i, j) の組み合わせを調べる全探索例 (C++) for (int i = 0; i < N; i++) { for (int j = i + 1; j < N; j++) { if (a[i] + a[j] == K) { ans++; } } }

② ソート ＋ 二分探索 (`std::lower_bound`)

$N = 10^5$ 程度で全組を走査する二重ループは、処理回数が約10¹⁰回になり実行時間が厳しくなります。配列を std::sort で昇順に並び替え、std::lower_bound（二分探索）を使うことで、$O(N \log N)$ に高速化できます。

// ソート後に二分探索で条件を満たす要素を探す (C++) sort(a.begin(), a.end()); auto it = lower_bound(a.begin(), a.end(), target);

③ 累積和 (Prefix Sum)

「任意の区間 $[L, R]$ の合計値」をクエリごとに $O(1)$ で一瞬で求めたい時に使います。あらかじめ先頭からの和を前計算（$O(N)$）しておくことで、配列に負の数が含まれていても使えます。

// 累積和の例 (C++) // S[i] に先頭 i 個の和を前計算 // 区間 [L, R] の和 = S[R + 1] - S[L] long long sum = S[R + 1] - S[L];

④ グリッド・配列のシミュレーション

「コマが上下左右に動く」「指示通りに操作を $K$ 回繰り返す」といった問題です。問題文の指示をそのまま素直にコード（二次元配列など）へ落とし込む力（実装力）が試されます。

2. TLEを避けるために計算回数を見積もる

灰コーダーが一番ハマりやすいのが「答えは合っているのに TLE（時間制限超過）になる」という罠です。

⚡ 10⁸回という値を速度保証にしない

時間制限は問題ごとに異なります。計算回数から時間を考える際は、言語・処理内容・定数倍・入出力のコストも確認してください。
- $N = 10^5$ のときに $O(N^2)$ の二重ループを書く $\rightarrow$ $10^{10}$ 回になり実行時間が厳しくなる可能性が高い！
- 二分探索やソートを用いて $O(N \log N)$ に落とす必要があります。

3. 提出前に必ず確認！「ポカミス防止」チェックリスト

誤答へのペナルティや対象となる判定はコンテストのルールによって異なります。提出ボタンを押す前に以下をチェックしましょう。

  • オーバーフローのチェック: 大きな数値の掛け算（$10^5 \times 10^5 = 10^{10}$）を int 型で受けていないか？（long long を使う）
  • $N = 1$ のコーナーケース: 要素が1個だけのとき、配列外参照やループ不成立が起きないか？
  • 初期化忘れ: ループやテストケースの先頭で、合計値変数 sum = 0; をリセットしているか？
  • Pythonの実行環境: CPythonとPyPyで速度やメモリ使用量が変わります。PyPyが常に速いわけではないため、処理内容と利用可能な環境を確認し、必要に応じて実測します。

4. コンテスト本番の立ち回り Tips

💡 A・B 問題の早解きでアドバンテージを取る

ABC コンテストでは、A・B問題を安定して解けるようにすると、次の問題を考える時間を確保しやすくなります。
C問題で詰まった時は、焦らず手元のノートに $N = 3$ や $N = 4$ の具体的な小さな例を手書きで書いて観察する のが解法のヒントを見つける一番の近道です！
